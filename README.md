# Indian Tourism SaaS

A separate SaaS foundation for Indian tourism: destination discovery, AI itinerary planning, paid travel plans, partner/affiliate marketplace, customer dashboards, and future Supabase/Razorpay integrations.

## Architecture
- Next.js App Router + TypeScript
- Supabase Auth/PostgreSQL/RLS/Storage
- AI itinerary generation
- Tourism destination/catalogue
- Affiliate and partner tracking
- Razorpay-ready payments
- Customer and admin dashboards
- SEO-ready destination pages

This repository currently contains the initial application foundation. Secrets and API keys must be supplied through environment variables and must not be committed.
